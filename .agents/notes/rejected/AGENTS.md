# AGENTS.md —— 否决区规则（自动加载）

> 进 `.agents/notes/rejected/` 子树即加载本文。

## 否决即留痕

1. **提案原文冻结**：被否决的提案保留 `## Proposal` 与落选理由，**不改写成现在时**（判据 1.8：rejected 出现 `## Decision` 即 FAIL）。
2. **判定只在 Status 行**：`Status: rejected — <一行理由>`；路径即标签，理由不散落在正文多处。
3. **可复活但须新条**：条件变化后要重启同一方案 → 新建一条 `proposed/`（链入本否决条），禁止把旧条移出 `rejected/`。

## 何时进本区

- 评审后明确不做（成本/风险/收益不成立），且理由对未来有检索价值；
- 与 `archived/` 的区别：`archived/` 是**曾经落地、后被取代**的历史快照；`rejected/` 是**从未落地**的否决提案。
