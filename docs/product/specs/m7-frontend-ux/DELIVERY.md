## 1. 交付范围

桌面端（desktop/）全页面 UX 重构：傻瓜式操作 + 极简 UI。核心变化：

- **首启闭环**：全局未配置引导卡 → 设置页三步连接向导（真实可执行的 admin token 获取指引）
  → 单一原子按钮「测试并保存」（失败零落盘、keyring 半失败回滚快照）
- **PRD 关键指标落地**：设备密钥创建即自动复制；「接入配置」弹窗给数据面 base_url 与
  Anthropic/OpenAI 片段（bash/PowerShell 双版本）；scope 白名单实证修复放行非默认端口
- **说人话**：导航中文化（总览/服务/设备密钥/用量统计/代理/设置）、全枚举彩点+中文词、
  相对时间与人性化数字、OS 通知中文、失败统一 toast
- **防呆**：明文弹窗自动复制+误关拦截、危险操作二次确认、busy 防关、置灰原因说明、
  模板不覆盖手动输入、测速失败内联切换线路+重测
- **安全纪律保持**：client.ts/schemas.ts 契约零漂移；CSP 未放宽；密钥不落盘不进日志；
  剪贴板 60s 自清唯一入口（epoch 防竞态）
